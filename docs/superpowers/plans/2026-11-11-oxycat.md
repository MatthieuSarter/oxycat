# Oxycat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A portable Rust desktop app (egui) and CLI that catalogs storage media into one SQLite file per medium and
searches/browses them offline, replacing Cathy 2.33.

**Architecture:** One crate, one binary `oxycat` (GUI by default, CLI with a sub-command). Pure business logic lives in
`src/core/` (no I/O, unit-tested without mocks); `src/catalog/` owns SQLite files (schema, store, scanner, queries);
`src/search.rs` fans a query out over catalogs on a bounded thread pool; `src/platform/` wraps OS calls; `src/gui/` is a
thin eframe layer calling the above. Headless engine + CLI land first (Tasks 1–12), GUI after (13–17), CI last (18).

**Tech Stack:** Rust 2024 (stable 1.98), eframe/egui + egui_extras, rusqlite (`bundled`), walkdir, rayon, clap
(derive), serde + toml, chrono, unicode-normalization, opener, rfd, windows-sys (Windows), libc (Unix), tempfile (dev).

**Spec:** [docs/superpowers/specs/2026-11-11-oxycat-design.md](../specs/2026-11-11-oxycat-design.md) — read it first;
section numbers below (§x) refer to it. Mockup: `docs/superpowers/specs/2026-11-11-oxycat-mockup.html`.

## Global Constraints

- License **EUPL-1.2**; every dependency MIT, Apache-2.0, BSD, Zlib, Unicode-3.0, ISC or public domain (checked by
  `cargo deny check licenses`, Task 18).
- Edition 2024, `rust-version = "1.98"`. Max line length 120 (`rustfmt.toml: max_width = 120`).
- `cargo clippy --all-targets -- -D warnings` clean, with `[lints.clippy] pedantic = "warn"` in `Cargo.toml`.
- Portable: nothing in the registry or `AppData`. Catalog dir = `--catalogs <dir>`, else env `OXYCAT_CATALOGS`
  (ignored if empty), else the executable's directory. Settings file `oxycat.toml` lives in the catalog dir.
- Never write to the cataloged media. No network access of any kind.
- One SQLite file per catalog, `<file stem>.db`, rollback journal (never WAL), `PRAGMA user_version = 1`.
- **Never keep a SQLite connection open between operations** (open, query, drop). On Windows an open handle blocks
  the atomic rename that replaces a catalog.
- Scanning and searching never run on the UI thread. Search thread pool = `max(1, available_parallelism - 1)`.
- Size units are decimal: `K`=10³, `M`=10⁶, `G`=10⁹, `T`=10¹², case-insensitive.
- Timestamps stored as UTC Unix seconds; displayed and entered in local time.
- Every user-visible string goes through `i18n::Strings` (FR/EN/ES). Code, comments and docs in English.
- Pure logic goes in `src/core/` — no filesystem, DB, clock, env or locale reads there; callers pass those in.
- Coverage: `cargo llvm-cov` line coverage ≥ 80 % (aim 90 %) over the crate **excluding** `src/gui/`,
  `src/platform/`, `src/main.rs` (thin I/O shells; documented in `docs/development.md`).
- Git: branch `main`; Conventional Commits with gitmoji (`feat(search): ✨ …`); signed commits only; **run
  `git commit` only after the owner has approved committing** (the owner may approve once for the whole plan). Never
  create or edit `CHANGELOG.md`.

## Review Focus

1. **Catalog in use while being replaced** (a GUI/other connection open on Windows) → replace fails cleanly with a
   "catalog in use" error and the old catalog stays intact. Test in Task 7.
2. **Awkward file names and paths** (accents, `%`/`_` in names, paths longer than 260 characters, non-UTF-8 names on
   Linux) → scanned without crash (lossy names), searchable literally. Tests in Tasks 2, 9 and 10.
3. **Pattern edge inputs** (empty, lone `|`, `||`, two `*`, `100%`, `my_file`) → empty = match all, two inner `*` =
   a clear error, LIKE metacharacters matched literally. Tests in Tasks 2 and 10.
4. **Medium vanishing or unreadable mid-scan** (nonexistent source, permission-denied folder) → nonexistent source =
   error and nothing written; unreadable folder = skipped and counted, catalog still produced. Tests in Task 9.
5. **Foreign files in the catalog dir** (zero-byte `.db`, non-Oxycat SQLite, newer `user_version`, leftover `.tmp`)
   → listed as invalid with a reason (temp files ignored), never modified, never crash. Test in Task 7.
